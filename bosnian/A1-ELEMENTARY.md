# 🇧🇦 BOSNAKÇA/KARADAĞCA (BOSANSKI/CRNOGORSKI) - A1 SEVİYESİ

## 📌 A1 Seviyesi Nedir?

**A1 (Početni/Beginner)** seviyesinde şunları yapabilirsiniz:
- Basit selamlaşmalar
- Temel günlük konuşmalar
- Kişisel bilgiler
- Basit sorular sorma ve cevaplama

## 📚 BÖLÜM 1: BOSNAKÇA ALFABE

### Bosnakça Alfabe (30 harf - Türkçe'ye benzer)

```
A  B  C  Č  D  Dž  Đ  E  F  G  H  I  J  K
L  Lj  M  N  Nj  O  P  R  S  Š  T  U  V  Z  Ž
```

**Özel Harfler:**
- **Č** - "ch" gibi
- **Š** - "sh" gibi
- **Ž** - "zh" gibi
- **Dž** - "dzh" gibi
- **Đ** - "dj" gibi
- **Lj** - "ly" gibi
- **Nj** - "ny" gibi

### Türkçe ile Karşılaştırma

| Aspekt | Türkçe | Bosnakça |
|--------|--------|----------|
| **Harf Sayısı** | 29 | 30 |
| **Benzerlik** | ÇOK YÜKSEK | - |
| **Telaffuz** | Yazıldığı gibi | Yazıldığı gibi |

**Bosnakça Türkçeye çok benzerdir!**

## 📖 BÖLÜM 2: TEMEL KELİMELER

### Selamlaşmalar (Pozdravi)

```
Zdravo          - Merhaba
Dobar dan       - İyi gün
Dobra večer     - İyi akşam
Dobar noć       - İyi gece
Doviđenja       - Hoşça kalın
Do uskoro       - Sonra görüşürüz
Kako si?        - Nasılsın?
Kako ste?       - Nasılsınız? (resmi)
```

**Türkçe Karşılaştırması:**
- Bosnakça "Zdravo" = Türkçe "Merhaba"
- Bosnakça "Dobar dan" = Türkçe "İyi gün"
- Bosnakça "Doviđenja" = Türkçe "Hoşça kalın"

**Örnek Diyalog:**

```
A: Zdravo! Kako si?
   (Merhaba! Nasılsın?)

B: Zdravo! Dobro sam, hvala. A ti?
   (Merhaba! İyi, teşekkür ederim. Sen?)

A: Ja sam dobro. Hvala!
   (Ben iyiyim. Teşekkür ederim!)
```

## 🔤 BÖLÜM 3: BOSNAKÇA DİLBİLGİSİ

### "BITI" Fiili (Olmak)

**Bosnakça ve Türkçenin en büyük benzerliği budur!**

```
Ja sam         - Ben (-yim)
Ti si          - Sen (-sin)
On/Ona/Ono je  - O (-dir)
Mi smo         - Biz (-yız)
Vi ste         - Siz (-siniz)
Oni/One/Ona su - Onlar (-dırlar)
```

**Türkçe Karşılaştırması:**

| Bosnakça | Türkçe | Benzerlik |
|----------|--------|-----------|
| Ja sam | Ben-yim | %90 |
| Ti si | Sen-sin | %90 |
| On je | O-dur | %90 |
| Mi smo | Biz-iz | %90 |
| Vi ste | Siz-siniz | %90 |
| Oni su | Onlar-dır | %90 |

**Örnekler:**

```
Ja sam sretan.
(Ben mutluyum.)
Türkçe: Ben mutluyum.

Ti si učitelj.
(Sen öğretmensin.)
Türkçe: Sen öğretmensin.

On je doktor.
(O doktordur.)
Türkçe: O doktordur.

Mi smo prijatelji.
(Biz arkadaşız.)
Türkçe: Biz arkadaşız.

Oni nisu kuće.
(Onlar evde değiller.)
Türkçe: Onlar evde değiller.
```

---

### "IMATI" Fiili (Sahip Olmak)

```
Ja imam        - Benim var
Ti imaš        - Senin var
On/Ona/Ono ima - Onun var
Mi imamo       - Bizim var
Vi imate       - Sizin var
Oni/One/Ona imaju - Onların var
```

**Örnekler:**

```
Imam brata.
(Ben bir erkek kardeşim var.)
Türkçe: Benim bir erkek kardeşim var.

Imaš kitabu?
(Senin bir kitaban var mı?)
Türkçe: Senin bir kitaban var mı?

Ona ima mačku.
(Onun bir kedisi var.)
Türkçe: Onun bir kedisi var.
```

## 📝 BÖLÜM 4: TEMEL DİYALOGLAR

### Diyalog 1: Tanışma

```
A: Zdravo! Moje ime je Ana. Kako se zoveš?
   (Merhaba! Benim adım Ana. Senin adın ne?)

B: Zdravo! Zovem se Marko. Drago mi je.
   (Merhaba! Benim adım Marko. Memnun.)

A: Drago mi je. Odakle si?
   (Memnun. Sen nereden?)

B: Ja sam iz Bosne. A ti?
   (Ben Bosna'dan. Sen?)

A: Ja sam iz Turske. Ja sam učiteljica. A ti?
   (Ben Türkiye'denim. Öğretmenim. Sen?)

B: Ja sam doktor.
   (Ben doktorum.)
```

---

### Diyalog 2: Kafede

```
Konobar: Dobar dan! Šta ćeš?
         (İyi gün! Ne istiyorsun?)

Gost: Kavu i komad kolača, molim.
      (Kahve ve bir kek parçası, lütfen.)

Konobar: Koja kava? Crna ili sa mlekom?
         (Ne tür kahve? Siyah mı yoksa sütlü mü?)

Gost: Crnu, molim.
      (Siyah, lütfen.)

Konobar: Evo. Još nešto?
         (İşte. Başka bir şey mi?)

Gost: Ne, hvala. Koliko je?
      (Hayır, teşekkür ederim. Ne kadar?)

Konobar: 5 maraka.
         (5 Marka.)
```

## 📚 BÖLÜM 5: UYGULAMALI ALIŞTIPMALAR

### Alıştırma 1: "Biti" Fiilini Tamamla

```
1. Ja _____ student.
   (Ben bir öğrenciyim.)
   Cevap: sam

2. Ti _____ iz Turske.
   (Sen Türkiye'denden.)
   Cevap: si

3. On _____ doktor.
   (O doktordur.)
   Cevap: je

4. Mi _____ prijatelji.
   (Biz arkadaşız.)
   Cevap: smo

5. Oni _____ kod kuće.
   (Onlar evde.)
   Cevap: su
```

---

### Alıştırma 2: Cümle Oluştur

```
1. (Ja / imam / brata)
   Cevap: Ja imam brata.

2. (Ti / biti / učitelj)
   Cevap: Ti si učitelj.

3. (On / biti / sretan)
   Cevap: On je sretan.

4. (Mi / biti / kod kuće)
   Cevap: Mi smo kod kuće.

5. (Oni / biti / iz Bosne)
   Cevap: Oni su iz Bosne.
```

## 🎯 A1 SEVİYESİ ÖZET

✅ **Başarılı olmanız için gereken şeyler:**
- BITI (olmak) fiilini akıcı kullanma
- IMATI (sahip olmak) fiilini öğrenme
- Temel kelimeleri hatırlama (100+ kelime)
- Basit cümleler kurma ve anlama
- Tanışma diyaloglarını yapabilme

- Gramer yapısı Türkçeye çok yakındır
- Fiil konjugasyonları benzerdir
- Kelime sırası benzerdir (SOV)
