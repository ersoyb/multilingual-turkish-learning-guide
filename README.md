### **Bölüm 2: Zaman Sistemleri (ÇIKTI İÇERİĞİ BAŞLARDAN ÖNCE AÇIKLAMA)**

#### 🔴 ÖNEMLİ: Türkçe Zaman Sistemi

Türkçede **3 ana zaman** vardır:
1. **Geçmiş Zaman:** -DI / -mIŞ / -yDI
2. **Şimdiki Zaman:** -Iyor / -Iyse / -mAktA
3. **Gelecek Zaman:** -yAcAk / -mAlI

```
TÜRKÇE ÖRNEĞİ:
- Ben kitap oku-du-m (Geçmiş definit)
- Ben kitap oku-muş-um (Geçmiş indefinit)
- Ben kitap oku-yor-um (Şimdiki)
- Ben kitap oku-yacak-ım (Gelecek)
```

**Dikkat:** Türkçede kişi ekleri (-im, -sin, -iz vb.) fiil kökünden sonra gelir.

## 🎓 Nasıl Kullanılır

1. **Başlangıç:** `TURKISH-GRAMMAR-BASICS.md` dosyasını okuyun
2. **Dil Seçimi:** Öğrenmek istediğiniz dil klasörüne gidin
3. **Seviye Başlangıcı:** A1 ile başlayın
4. **Sıralı Öğrenme:** Tüm konuları sırasıyla çalışın
5. **Karşılaştırma:** Her konuda Türkçe açıklamalarını dikkatlice inceleyip mantığı anlayın
6. **Uygulama:** Örnekleri tekrar edin ve kendi cümleler oluşturun
