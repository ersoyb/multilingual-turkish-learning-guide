# 🇰🇷 KORECE (한국어/KOREAN) - A1 SEVİYESİ (BAŞLANGIC)

## 📌 A1 Seviyesi Nedir?

**A1 (초급/Beginner)** seviyesinde şunları yapabilirsiniz:
- Basit selamlaşmalar
- Temel günlük konuşmalar
- Kişisel bilgiler
- Basit sorular sorma ve cevaplama

---

## 📚 BÖLÜM 1: KORECE ALFABE - HANGUL (한글)

### Hangul Nedir?

Korece'nin kendi alfabesi **Hangul (한글)**'dir. 1443 yılında Kral Sejong tarafından icat edilmiştir.

### Temel Sesler (Consonants)

**Düz Sessizler:**
```
ㄱ (g)    ㄴ (n)    ㄷ (d)    ㄹ (r/l)
ㅁ (m)    ㅂ (b)    ㅅ (s)    ㅈ (j)
ㅊ (ch)   ㅋ (k)    ㅌ (t)    ㅍ (p)
ㅎ (h)    ㅇ (ng)
```

**Ünlüler (Vowels):**
```
ㅏ (a)    ㅑ (ya)   ㅓ (eo)   ㅕ (yeo)
ㅗ (o)    ㅛ (yo)   ㅜ (u)    ㅠ (yu)
ㅡ (eu)   ㅣ (i)
```

### Örnek Kelimeler

```
가 (ga) - Harf A
나 (na) - Harf NA
다 (da) - Harf DA
라 (ra) - Harf RA
마 (ma) - Harf MA
```

## 📖 BÖLÜM 2: TEMEL KELİMELER

### Selamlaşmalar (인사)

```
안녕하세요     (Annyeonghaseyo)    - Merhaba (resmi)
안녕             (Annyeong)          - Merhaba (arkadaş arası)
좋은 아침입니다 (Joheun achim)      - Günaydın
안녕히 가세요   (Annyeonghi gaseyo) - Hoşça kalın
다시 만나요     (Dasi mannayo)      - Sonra görüşürüz
```

**Türkçe Karşılaştırması:**
- Korece'de resmi (존댓말) ve arkadaş arası (반말) farklı selamlaşmalar vardır
- Türkçe'de bu kadar değişkenlik yoktur

**Örnek Diyalog:**

```
A: 안녕하세요! 어떻게 지내세요?
   (Annyeonghaseyo! Eotteohge jinaeseyo?)
   (Merhaba! Nasılsınız?)

B: 안녕하세요! 잘 지내요, 감사합니다. 너는?
   (Annyeonghaseyo! Jal jinaeyo, gamsahamnida. Neoneun?)
   (Merhaba! İyi, teşekkür ederim. Sen?)

A: 나도 잘 지내요.
   (Nado jal jinaeyo.)
   (Ben de iyiyim.)
```

(Jeoneun seonsaengni-mipnida.)

## 🔤 BÖLÜM 3: KORECE DİLBİLGİSİ

### "이다" (Ida) Fiili - (Olmak)

Korece'de "olmak" fiili **이다 (ida)**'dır.

```
나는 학생입니다.          (Naneun haksaengipnida.)      - Ben öğrenciyim.
너는 선생님입니다.        (Neoneun seonsaengni-mipnida.) - Sen öğretmensin.
그/그녀는 의사입니다.     (Geu/Geunyeoneun uisaipnida.) - O doktordur.
우리는 친구입니다.        (Urineun chingguipnida.)       - Biz arkadaşız.
당신들은 학생입니다.      (Dangsindeureun haksaengipnida.) - Siz öğrencisiniz.
그들은 의사입니다.        (Geudeureun uisaipnida.)       - Onlar doktordur.
```

**Türkçe Karşılaştırması:**
- Korece'de "이다" fiili "입니다" (polite) veya "야" (casual) şekline dönüşür
- Türkçe'de "-yim/-sin/-dir" eklenişi daha basittir

---

### "있다" (İtda) - Var, Bulunmak

```
나는 형이 있습니다.       (Naneun hyeongi isseumnida.)   - Benim erkek kardeşim var.
너는 책이 있어?           (Neoneun chaegi isseo?)         - Senin bir kitaban var mı?
그녀는 고양이가 있어요.   (Geunyeoneun goyangi-ga isseyo.) - Onun bir kedisi var.
```

---

### Hâller ve Partiküller (조사)

Korece'de Türkçe'te olduğu gibi Hâl Sistemi vardır!

```
는 (neun) - Konusu belirtir (Topic Particle)
가 (ga)   - Konuyu belirtir (Subject Particle)
을/를 (eul/reul) - Nesnesi (Object Particle)
에 (e)    - Yerdeki (Locative)
에서 (eseo) - Yerinden (Source)
```

**Örnek:**

```
나는 학교에 간다.
(Naneun haggyo e ganda.)
(Ben okula gidiyorum.)

저는 한국에서 왔습니다.
(Jeoneun Hanguk-eseo wasseubnida.)
(Ben Kore'den geldim.)
```

## 📝 BÖLÜM 4: TEMEL DİYALOGLAR

### Diyalog 1: Tanışma

```
A: 안녕하세요! 제 이름은 안나입니다. 이름이 뭐예요?
   (Annyeonghaseyo! Je irerumeun Annaipnida. Ireumi mwoyeyo?)
   (Merhaba! Benim adım Anna. Adın ne?)

B: 안녕하세요! 저는 마르코입니다. 만나서 반갑습니다.
   (Annyeonghaseyo! Jeoneun Makeukoipnida. Mannaseo bangapseumnida.)
   (Merhaba! Ben Marco. Tanıştığımız için sevindim.)

A: 반갑습니다. 어디 출신이세요?
   (Bangapseumnida. Eodi chulsin-iseyo?)
   (Memnun. Sen nereden?)

B: 저는 한국에서 왔습니다. 너는?
   (Jeoneun Hanguk-eseo wasseubnida. Neoneun?)
   (Ben Kore'den. Sen?)

A: 저는 터키에서 왔습니다. 저는 선생님입니다. 너는 뭐해?
   (Jeoneun Teokiseseo wasseubnida. Jeoneun seonsaengni-mipnida. Neoneun mwohae?)
   (Ben Türkiye'denim. Öğretmenim. Sen ne iş yapıyorsun?)

B: 저는 의사입니다.
   (Jeoneun uisaipnida.)
   (Ben doktorum.)
```
